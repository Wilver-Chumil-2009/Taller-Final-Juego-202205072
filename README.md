# Taller-Final-Juego-202205072
En este repositorio encontrara el análisis, diagrama, código del juego Car-Runner-Esquiva los Obstáculos

# Fase 1: Análisis
Realicé un análisis sobre el funcionamiento del videojuego. El jugador controla un carro que debe avanzar por la carretera y esquivar los diferentes carros que aparecen como obstáculos.
El objetivo es evitar las colisiones y conseguir avanzar durante el mayor tiempo posible. Si el jugador choca con otro carro, el juego termina.

# Fase 2: Diagrama de flujo
El diagrama de flujo representa el funcionamiento del juego desde su inicio hasta el final.
Primero comienza el juego y aparece el carro del jugador. Después empiezan a aparecer otros carros como obstáculos. El jugador debe mover su carro para esquivarlos.
El programa comprueba si ocurrió una colisión. Si no choca, el juego continúa; si choca, el juego termina.

# Fase 3: Código
En esta fase se realizó el código del videojuego utilizando Python. El código contiene las instrucciones necesarias para controlar el funcionamiento del juego.
Se utilizan variables para almacenar información importante, como la posición del carro, los obstáculos y otros datos necesarios durante la partida.
También se utilizan condiciones para comprobar diferentes situaciones, principalmente para saber si el jugador esquivó correctamente un carro o si ocurrió una colisión.
Los ciclos permiten que el juego continúe funcionando mientras el jugador siga jugando, haciendo que los obstáculos aparezcan y que el carro pueda seguir avanzando.
El código fue realizado de manera sencilla para que cada parte del programa pueda cumplir una función específica dentro del videojuego.

# Fase 4: GitHub
En esta última fase se presenta el proyecto completo en GitHub, mostrando las diferentes etapas realizadas: análisis, diagrama de flujo y código.
El programa puede ejecutarse desde Visual Studio Code utilizando Python para comprobar el funcionamiento del videojuego.
